# Базовые концепции

Всё, что общего для `<jqx-grid>`, `<jqx-tree>` и `<jqx-form>`: правила
разрешения источника, слияние опций, инъекция ассетов и роутер пакета.
Каждая страница виджета ([grid](grid.md) · [tree](tree.md) ·
[form](form.md)) опирается на эти правила.

## 1. Источники — что принимает `source=`

Каждый виджет принимает `source`, указывающий на DRF-эндпоинт:

| Значение | Результат |
| --- | --- |
| класс viewset'а из `GridViewSet.create()` / `TreeViewSet.create()` / `FormViewSet.create()` | URL разрешается автоматически |
| экземпляр viewset'а | то же самое |
| строка (`"/api/products/"`) | используется как есть |

Разрешение выполняется `jqxwidgets.viewsets.source_url()`; при неудаче (нет
`source` или у viewset'а нет зарегистрированного URL) виджет выбрасывает
`ImproperlyConfigured` с сообщением, указывающим виджет.

## 2. Порядок слияния опций

Все виджеты сливают опции одинаково (побеждает последний источник):

```
атрибуты класса  →  config=  →  **options
```

* **атрибуты класса** — задаются на подклассе `Grid`/`Tree`/`Form`;
* **config=** — dict (или `GridConfig` для грида), переданный в конструктор;
* **\*\*options** — любая jqx-опция, переданная именованным аргументом.

Для грида цепочка продолжается ниже: `extra` viewset'а → ответ
`<source>config/` → встроенные значения по умолчанию (см.
[grid.md](grid.md) §3.4).

## 3. Один бандл на страницу

`{{ grid }}` / `{{ tree }}` / `{{ form }}` рендерят три вещи: `<link>` таблицы
стилей, инлайновый скрипт-загрузчик и сам кастомный элемент. Загрузчик:

* разрешает хешированные имена файлов через `manifest.json` (инвалидация кэша);
* внедряет `polyfills-*.js` и `main-*.js` **один раз на страницу**, даже если
  отрендерено несколько виджетов (защита `window.__JQXWIDGETS_LOADED__`);
* пишет предупреждение в лог, если в манифесте нет JS-записей.

Рендерить два виджета на одной странице безопасно — второй переиспользует уже
зарегистрированные ассеты.

## 4. Роутер пакета и URL

Все фабрики (`GridViewSet.create`, `TreeViewSet.create`, `FormViewSet.create`)
регистрируют свой viewset в `rest_framework.routers.SimpleRouter` уровня
пакета (`jqxwidgets.router.router`). `urls.py` приложения должен подключить
его один раз:

```python
urlpatterns = [
    path('api/', include('jqxwidgets.urls')),
]
```

Basename'ы маршрутов дедуплицируются между **всеми** фабриками — когда две
модели разрешаются в одно имя, вторая получает префикс `app_label_` (а
источник формы — суффикс `-form`). Reverse работает через неймспейс
приложения: `reverse('jqxwidgets:<basename>-list')`.

## 5. Своя разметка

Каждый виджет рендерит шаблон из `jqxwidgets/templates/jqxwidgets/` с одинаковой
формой контекста (`source`, `config` в JSON, `assets` плюс ключи, специфичные
для виджета). Чтобы изменить разметку, унаследуйте виджет и переопределите
`__html__()` или `template_name`.
